# Izvori i struktura podataka

| Izdavatelj | Katalog podataka |
|---|---|
| Grad Zagreb | [Proračun Grada Zagreba](https://data.gov.hr/ckan/dataset/proracun-grada-zagreba-2026) |
| Grad Split | [Proračun Grada Splita](https://data.gov.hr/ckan/dataset/proracun) |
| Grad Rijeka | [Proračun Grada Rijeke](https://data.gov.hr/ckan/dataset/proracun-grada-rijeke-na-4-razini-konta) |
| Grad Osijek | [Proračun Grada Osijeka](https://data.gov.hr/ckan/dataset/proracun-grada-osijeka-za-2026) |

U mapi podataka aplikacije `registry.json` sadrži katalog dokumenata po gradovima i godinama te izvorne poveznice. Sažeti i detaljni zapisi hrane usporedbe, a `stories.json` povezuje izdvojene priče sa službenim obrazloženjima i drugim navedenim izvorima. Stavke se mogu provjeriti kroz poveznicu **Izvori** u javnom demu.
